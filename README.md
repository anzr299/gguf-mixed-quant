# gguf-mixed-quant

Sensitivity-driven mixed-precision GGUF quantization for [llama.cpp](https://github.com/ggerganov/llama.cpp), powered by [NNCF](https://github.com/openvinotoolkit/nncf).

Standard GGUF quantization assigns precision by hand-tuning it. This tool uses **per-layer sensitivity analysis** to dynamically steal bits from layers that don't need them and give them to layers that do — like Robin Hood.

---

## Get Started (60 seconds)

**Prerequisites:** Python ≥ 3.10 and a working [llama.cpp](https://github.com/ggerganov/llama.cpp) build (you need `llama-quantize` and `convert_hf_to_gguf.py`).

```bash
# 1. Install
pip install git+https://github.com/anzr299/gguf-mixed-quant.git

# 2. Run (one command — handles everything)
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset Q4_K \
    --adaptive-bands \
    --output my-model-q4k-mixed.gguf
```

That's it. The output GGUF has **better perplexity** than standard Q4_K because insensitive layers get downgraded and the saved bits promote sensitive layers to higher precision.

> **Note:** Everything runs on CPU by default — no GPU required. The default metric (`max_activation_variance`) uses the `wikitext` calibration dataset automatically (~5-10 min). For a faster data-free alternative, pass `--metric weight_quantization_error`.

## Two Assignment Modes

### Auto mode (recommended)

The algorithm automatically picks optimal per-layer types based on sensitivity analysis. Use `--adaptive-bands` for sensitivity-aware band sizing:

```bash
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset Q4_K \
    --adaptive-bands \
    --output model-q4k-mixed.gguf
```

Without `--adaptive-bands`, the algorithm uses maximum-differentiation band ratios (equivalent to spread=1.0):

```bash
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset Q4_K \
    --output model-q4k-mixed.gguf
```

### Manual mode

You specify the exact quant types and what percentage of layers gets each:

```bash
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset Q4_K \
    --tiers Q4_K Q5_K Q6_K \
    --tier-ratios 0.65 0.20 0.15 \
    --output model-q4k-manual.gguf
```

## IQ (Importance) Quantization

IQ presets (IQ2_XXS through IQ4_NL) require an importance matrix file generated by llama.cpp's `llama-imatrix`. Pass it with `--imatrix`:

```bash
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset IQ3_S \
    --imatrix /path/to/imatrix.dat \
    --adaptive-bands \
    --output model-iq3s-mixed.gguf
```

Extreme compression with IQ2_XXS:

```bash
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset IQ2_XXS \
    --imatrix /path/to/imatrix.dat \
    --adaptive-bands \
    --output model-iq2xxs-mixed.gguf
```

> **Note:** IQ1_S, IQ1_M, IQ2_XXS, IQ2_XS, IQ2_S, and IQ3_XXS require `--imatrix` and will fail without it. IQ3_S, IQ4_XS, and IQ4_NL benefit from an imatrix but work without one. K-quant presets (Q2_K through Q8_0) do not require an imatrix.

## How It Works

```
┌─────────────────┐     ┌──────────────────────┐     ┌───────────────────┐
│  HuggingFace    │────▶│  NNCF Sensitivity    │────▶│  Robin Hood       │
│  Model (FP16)   │     │  Analysis            │     │  Type Assignment  │
└─────────────────┘     └──────────────────────┘     └───────┬───────────┘
                                                             │
                        ┌──────────────────────┐             │
                        │  Quantized GGUF      │◀────────────┘
                        │  (llama-quantize)     │
                        └──────────────────────┘
```

1. **Compute sensitivity scores** — NNCF measures how much each layer's output degrades under quantization
2. **Rank layers** — most-sensitive layers need higher precision, least-sensitive can tolerate lower
3. **Assign per-layer types** — layers are sorted by sensitivity and assigned to bands (base, +1, +2), each mapped to progressively higher-precision quant types
4. **Quantize** — apply per-tensor type overrides via `llama-quantize --tensor-type-file`

With `--adaptive-bands`, the band sizes adapt to the model's sensitivity distribution: models with clustered scores get a larger base band, while models with spread-out scores get more differentiation across bands.

```bash
# Option A: pip install directly from GitHub
```

## More Examples

### Different presets

```bash
# Q2_K — extreme compression
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset Q2_K \
    --adaptive-bands \
    --output model-q2k.gguf

# Q3_K — aggressive compression
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset Q3_K \
    --adaptive-bands \
    --output model-q3k.gguf

# Q5_K — high quality
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset Q5_K \
    --adaptive-bands \
    --output model-q5k.gguf
```

### Already have an F16 GGUF?

Skip the HF→GGUF conversion step (saves time on large models):

```bash
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --preset Q4_K \
    --f16-gguf /path/to/my-model-f16.gguf \
    --adaptive-bands \
    --output model-q4k.gguf
```

### Data-aware metrics (better results, requires calibration)

```bash
# Best results — max activation variance with wikitext calibration
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --metric max_activation_variance \
    --dataset wikitext \
    --preset Q4_K \
    --adaptive-bands \
    --output model-q4k.gguf

# Reasoning data for math-focused models
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --metric max_activation_variance \
    --dataset reasoning \
    --preset Q4_K \
    --adaptive-bands \
    --output model-math.gguf
```

### Tuning calibration parameters

```bash
# Custom sequence length and subset size
gguf-mixed-quant \
    --model Qwen/Qwen3.5-0.8B \
    --metric max_activation_variance \
    --dataset wikitext \
    --seq-len 512 \
    --subset-size 64 \
    --preset Q4_K \
    --adaptive-bands \
    --output model-q4k.gguf
```

### Exploring sensitivity scores and presets

```bash
# List all available metrics
gguf-mixed-quant --list-metrics

# List all presets (K-quant and IQ)
gguf-mixed-quant --list-presets

# List named datasets with their default seq_len and subset_size
gguf-mixed-quant --list-datasets
```

## Sensitivity Metrics

| Metric | Data | Description |
|--------|:---:|-------------|
| `weight_quantization_error` | No | Inverted 8-bit quantization noise per layer (fast, data-free) |
| `hessian_input_activation` | Yes | HAWQ: Hessian trace × quantization error |
| `mean_activation_variance` | Yes | Mean activation variance × quantization error |
| `max_activation_variance` | Yes | **Default.** Max activation variance × quantization error |
| `mean_activation_magnitude` | Yes | Mean activation magnitude × quantization error |

## Calibration Datasets

Each named dataset has tuned defaults for `--seq-len` and `--subset-size`:

| Name | seq_len | subset_size | Description |
|------|--------:|------------:|-------------|
| `wikitext` | 256 | 128 | Wikipedia text (general language modeling) |
| `nemotron` | 8192 | 32 | Nemotron SFT mix (math, science, chat, swe, instruction following) |
| `reasoning` | 512 | 128 | GSM8K math reasoning chains |
| `coding` | 1024 | 64 | Python code generation outputs |

You can also pass any HuggingFace dataset name directly via `--dataset`. Custom datasets fall back to `--seq-len 256 --subset-size 128` unless overridden.

## CLI Reference

```
gguf-mixed-quant [options]

Model & output:
  --model MODEL             HuggingFace model ID or local path
  --output OUTPUT            Output GGUF file path (default: <model>-mixed.gguf)
  --f16-gguf F16_GGUF        Path to existing F16 GGUF (skip conversion)
  --llama-cpp LLAMA_CPP      Path to llama.cpp directory (auto-detected)

Quantization:
  --preset PRESET            Base preset: Q2_K, Q3_K, Q4_K, Q5_K, Q6_K, Q8_0,
                             IQ2_XXS, IQ2_XS, IQ2_S, IQ3_XXS, IQ3_S, IQ4_XS, IQ4_NL
  --imatrix IMATRIX          Importance matrix file (required for IQ presets)
  --adaptive-bands           Scale band ratios by sensitivity spread (auto mode only)

Manual mode (overrides auto):
  --tiers TYPE [TYPE ...]    Quant types per tier, lowest to highest precision
  --tier-ratios R [R ...]    Fraction of layers per tier (must sum to 1.0)

Sensitivity:
  --metric METRIC            Sensitivity metric (default: max_activation_variance)
  --dataset DATASET          Calibration dataset (default: wikitext)
  --subset-size N            Number of calibration samples (default: per-dataset)
  --seq-len N                Max sequence length (default: per-dataset)
  --group-size N             Quantization group size (default: 128)

Runtime:
  --device DEVICE            Device for model loading (default: cpu)
  --dtype {float32,float16,bfloat16}   Model dtype (default: float32)

Info:
  --list-metrics             List available sensitivity metrics
  --list-presets             List available quantization presets
  --list-datasets            List available named datasets
```

```bash
# Install dev dependencies

```

### Conformance tests

Conformance tests quantize a small model (SmolLM-135M) end-to-end and check quality using [Who-What-Benchmark](https://github.com/openvinotoolkit/openvino.genai/tree/master/tools/who_what_benchmark) methodology (sentence-transformer cosine similarity). They require a GPU and a built llama.cpp:

```bash
# Install conformance dependencies
pip install -e ".[dev,conformance]"

# Run conformance tests (requires ~/llama.cpp with built llama-quantize)
pytest tests/test_conformance.py -v -m conformance
```
